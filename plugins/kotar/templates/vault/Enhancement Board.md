# Enhancement Board

Request improvements with `/kotar <description>`; Claude evaluates them with the project's five checks, hands them to side sessions and merges them into local `main` (never pushes). Bugs: [[Bug Board]].

## How to steer
- Write in a note's **Guidance** section, change `priority` or add to `blockedBy`.
- Then run `/kotar` in chat with no arguments.

## Statuses
Same as [[Bug Board]].
